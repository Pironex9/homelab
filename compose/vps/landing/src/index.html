Komodo GitOps Migration

The Docker Compose stacks moved off Dockge and onto Komodo, and their definitions moved into this repository rather than being edited in place on the host. Komodo keeps a clone on the Docker host and deploys each stack from it, on an explicit pull and deploy rather than on every commit. One stack that builds from a third-party checkout stays on the host by design.

Resilient Storage

Three drives pooled into one 8.1 TB MergerFS volume, with a fourth held back for SnapRAID parity. It survives a single drive failure with no data loss, and a supervised SnapRAID daemon runs the weekly sync and scrub unattended.

Read the write-up

Self-hosted Tunnel

Selected services reach the public internet through Pangolin on a Hetzner VPS, joined to the homelab by a WireGuard tunnel. No third-party tunnel provider in the path and no ports forwarded on the home router.

Read the write-up

Backup System

Restic snapshots of the Proxmox host to a local repository, mirrored to an NFS share on a second machine that is not always on. A weekly cron job prunes to seven daily, four weekly and three monthly snapshots, then runs a repository integrity check.
